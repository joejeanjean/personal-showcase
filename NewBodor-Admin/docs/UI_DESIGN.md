# 界面设计 — NewBodor 企业管理后台

**Author**: 前端开发者
**技术栈**: 原生 HTML/CSS/JS 单页应用（零构建），随 Electron 本地托管

## 1. 设计目标

复现云之家「企业管理后台」的信息架构与视觉，并保证可用性。参考截图（OCR 还原）：
- 左侧导航：团队概况 / 通讯录 / 应用管理 / 计费服务 / 同事圈 / 信息安全平台 / 系统设置 / 开放平台 / 系统日志
- 顶部：企业信息、当前管理员、退出
- 内容区首屏：企业卡片 + 团队概况统计

## 3. 视觉规范

- 品牌主色：`#ff7a1a`（橙），用于品牌区、激活导航、按钮、关键数字。
- 背景：`#f4f6f9`；卡片白底 `#fff`，圆角 `12px`，边框 `#eaeef3`。
- 字体：`-apple-system,'Segoe UI',Roboto,'Microsoft YaHei',sans-serif`，正文 14px。
- 徽章：`green`（启用/已登录）、`gray`（停用/未登录）、`red`（高危）。

## 4. 页面清单

### 4.1 登录
- 居中卡片，品牌渐变背景。
- 输入企业邮箱 + 密码，登录后进入后台。

### 4.2 团队概况（首屏）
- 企业卡片：企业ID `19141476`、注册日期 `2020-08-18`、管理员 `许振`、企业名 `NewBodor 演示企业`。
- 统计卡片 4 个：总人数 `4551`、已登录 `4550`、未登录 `1`、部门个数 `880`。
- 子项：已设负责人部门 `745`、未设负责人部门 `135`。
- 关联表格：部门负责人分布、成员登录状态概览。

### 4.3 通讯录
- 左侧部门树（含成员数），右侧成员表格。
- 新增/编辑/删除部门与成员；设置负责人。
- 表格列：用户ID、姓名、部门、角色、登录状态、手机、邮箱、操作。

### 4.4 应用管理（轻应用）
- 卡片/表格展示：名称、图标、状态、描述、安装数。
- 每行可启停、编辑、删除。

### 4.5 计费服务
- 卡片：套餐、费用、到期日、用量占比、席位、已用席位、自动续费。
- 历史账单表格。

### 4.6 公共号
- 表格：名称、类型、粉丝、状态、操作。

### 4.7 同事圈
- 帖子流卡片：作者、内容、时间、点赞、评论。

### 4.8 信息安全平台
- 表单：登录策略、密码最小长度、MFA（类型）、会话超时、IP 白名单、数据加密、审计开关、水印。

### 4.9 系统设置
- 表单：企业名称、管理员邮箱、默认语言、时区、通知、允许注册、上传大小限制。

### 4.10 开放平台
- 表格：名称、AppKey、Secret（脱敏）、状态、调用量。
- 新增生成 AppKey/Secret；启用/停用。

### 4.11 系统日志
- 表格：时间、操作人、动作、对象、IP。
- 可按操作人/动作筛选、分页。

## 5. 交互与状态

- 使用 `fetch` 调用 `/api/*`，携带 `Authorization: Bearer <token>`。
- 加载态、空态、错误提示（toast）。
- 写操作后刷新数据；删除需二次确认。
- 会话过期（401）自动回到登录。

## 6. 响应性

目标桌面宽度 1280–1600。侧边栏固定 220px，主区自适应；表格可横向滚动。
