# 自研 NewBodor 企业协同平台成果展示

完全自研、可离线运行的一体化企业平台：通信平台实现 5 名员工工号登录、跨用户消息路由、单聊群聊与未读管理；管理后台覆盖通讯录、BPM、EHR、CRM、日历、AI 及开放平台，配置三级权限（超级管理员/部门管理员/普通员工）与审计日志；数字员工模块支持编制审批、跨部门资源分配、人机职责边界裁定及入离职全流程管理。前后端零依赖，交付即用。

## 成果亮点

- 自研 NewBodor 系统（完全自研、不依赖云之家）
- 通信平台（聊天 PC 端 + 企业管理后台）
- 跨系统协作平台（股份？BPM/EHR/CRM/日历/AI、开放平台等）
- 数字员工管理（编制/资源分配/职责边界/入离职审批）
- 权限模型（三级权限）
- 工号登录体系（110-114）
- 离线可运行、SQLite、REST API、鉴权、审计
